# Celovita izdanja bajki

Ovaj direktorijum sadrži 37 celovitih srpskih tekstova preuzetih iz tačno
zabeleženih revizija Srpskog Wikizvornika. Nijedan JSON nije napravljen od
kratkog prikaza radnje.

Svaki fajl sadrži:

- tačan naslov, autora i poznatog prevodioca;
- URL i ID revizije izvornog izdanja;
- broj reči, rečenica i stranica;
- status kompletnog audio-paketa;
- oznaku `sourceCoverage: verified`.

Tekstovi i pripadajuće oznake izvora koriste se pod licencom
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Link ka
konkretnoj izvornoj stranici prikazan je i u samoj aplikaciji.
